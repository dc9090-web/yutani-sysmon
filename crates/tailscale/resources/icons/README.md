# Icon

`io.github.dc.CosmicAppletTailscale-symbolic.svg` is Tailscale's dot-grid mark, supplied by DC (2026-11-24). It is drawn in one ink (the theme's foreground), keeping the mark's own dim and solid dots, so the same file serves light and dark panels. It is embedded in the binary and also installed to `hicolor/scalable/apps/` for the applet list. The state is shown by the coloured circle the applet draws over it, not by the mark.
